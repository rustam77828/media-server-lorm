# Media Server LORM

Система поддержки принятия решений для управления локальным медиа-хранилищем на базе Nextcloud.

## Что это

Проект реализует модель **LORM** (Layered Operational Responsibility Model) для управления медиа-сервером. Система собирает данные о состоянии сервера, объясняет происходящие процессы и помогает администратору принимать решения.

## Уровни LORM

| Уровень | Название | Что делает |
| :--- | :--- | :--- |
| **L0** | Знать | Инвентаризация: диски, контейнеры, сервисы, сеть |
| **L1** | Наблюдать | Сбор метрик: CPU, RAM, температура, uptime, логи |
| **L2** | Понимать | Объяснение: почему GPU греется, почему нужна перезагрузка |
| **L3** | Предлагать | Рекомендации: перезагрузить, обновить, проверить |
| **L4** | Действовать с одобрения | Выполнение после подтверждения |
| **L5** | Автономно | Политики: автоматические действия по правилам |

## Инфраструктура

- **Хост:** `mediaserver` (Ubuntu 26.04 LTS)
- **CPU:** Intel Core i5-2450M (4 threads)
- **RAM:** 7.2 GB
- **Диск sda:** 238.5 GB (системный)
- **Диск sdb:** 698.6 GB (медиа-хранилище, `/mnt/storage`)
- **Docker:** `nextcloud-app` (порт 8080), `nextcloud-db` (MariaDB 10.11)
- **Сеть:** локальная сеть, статический IP (диапазон 192.168.x.x)
- **Доступ:** только по SSH-ключам с доверенного устройства
- **Отказоустойчивость:** BIOS настроен на автозапуск после сбоя питания

## Технологии

- **Backend:** Python 3.x, FastAPI, Uvicorn
- **Frontend:** HTML, CSS, JavaScript
- **Система:** Linux, Docker, systemd
- **Данные:** системные метрики, логи, Docker API
